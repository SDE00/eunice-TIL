### 2. 특강: 자신감 살찌우기 (by Eddy)

| 주제 | 내용 |
|------|------|
| 자신감의 중요성 | 내 안에 내재된 **성격/생각/가치관**을 잘 표현해야 평가받을 수 있음 |
| 실행력 | 진로 고민은 짧게, 실행은 빠르게 |
| 표현력 | 내 생각을 빠르고 명확하게 전달하는 훈련 필요 |
| 침묵의 위험 | 조용히 있으면 평가받지 못함 → **내가 한 일은 어필** 필요 |
| 스타트업 선택 기준 | - 실제 매출 발생 (예: 무신사)<br>- 대표 철학 확인(인터뷰 등)<br>- 갑작스러운 성장기에는 입사 주의 |

**현업 현실 팁:**
- 사수가 있는 회사 → 좋은 첫 커리어 방향
- 네이버(수직적 문화) vs 카카오(개인 자율 중심)
- IT 직군은 빠르게 돌아감 → 생각보다 **빠른 결정/실행**이 중요
